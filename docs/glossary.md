# Glossary

- **Commit:** A named snapshot in repository history.
- **Working tree:** The files currently checked out for editing.
- **Staging area:** The changes selected for the next commit.
- **Branch:** A movable reference to a line of commits.
- **Remote:** A named repository location used for sharing history.
- **Clone:** A local copy of an existing repository.
- **Merge:** Integrating histories from two lines of development.
- **IDE integration:** Git features surfaced inside an editor or IDE, such as staging, diffing, history, and conflict resolution.
- **Hunk:** A contiguous block of changed lines within a file that can be staged on its own.
- **Merge tool:** An external program set with `merge.tool` and launched by `git mergetool` to resolve conflicts.
- **Diff tool:** An external program set with `diff.tool` and launched by `git difftool` to view changes.
- **Credential helper:** A component that stores and supplies Git credentials so they are not retyped on every push.
