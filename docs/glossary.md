# Glossary

- **Commit:** A named snapshot in repository history.
- **Working tree:** The files currently checked out for editing.
- **Staging area:** The changes selected for the next commit.
- **Branch:** A movable reference to a line of commits.
- **Remote:** A named repository location used for sharing history.
- **Clone:** A local copy of an existing repository.
- **Merge:** Integrating histories from two lines of development.
