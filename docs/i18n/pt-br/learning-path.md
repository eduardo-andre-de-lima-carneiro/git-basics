# Trilha de aprendizagem

Este curso foi criado para pessoas que estão começando a aprender Git ou migrando do Subversion.

1. Leia o Capítulo 1 para construir o modelo mental correto.
2. Conclua o Capítulo 2 e confirme o Git localmente com `git --version`.
3. Pratique o Capítulo 3 em um repositório descartável.
4. Repita os exercícios até o fluxo de trabalho se tornar previsível.

Cada seção deve combinar uma explicação curta, um exemplo de comando, a saída ou o resultado esperado e um pequeno exercício.
