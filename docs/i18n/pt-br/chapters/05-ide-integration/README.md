# Capítulo 5: Integração com IDEs e editores

A maior parte do trabalho diário com Git acontece dentro de um editor de código ou IDE. Os comandos dos capítulos anteriores continuam rodando por baixo; o editor acrescenta uma camada visual para preparar mudanças, ver diferenças, consultar o histórico, trocar de branch e resolver conflitos. Este capítulo explica primeiro as ideias compartilhadas e depois mostra como elas aparecem no Visual Studio Code, no Visual Studio e nas IDEs da JetBrains, seguido de um panorama de outros editores e de uma nota sobre fluxos assistidos por IA.
