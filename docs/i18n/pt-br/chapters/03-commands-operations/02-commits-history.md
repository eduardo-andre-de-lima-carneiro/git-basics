# 3.2 Commits e histórico

Alguns comandos úteis de inspeção são:

```bash
git log --oneline --decorate --graph
git show <commit>
git diff <commit-a> <commit-b>
```

Prefira commits focados, cada um representando uma alteração lógica. O histórico fica mais fácil de revisar quando as mensagens de commit usam uma descrição específica e no modo imperativo.
