# 1.3 O modelo distribuído do Git

Um repositório individual normalmente tem uma árvore de trabalho, um histórico local e repositórios remotos opcionais. Um remoto é um ponto de colaboração, não a definição do Git.

As operações comuns têm finalidades diferentes:

- `clone` copia um repositório.
- `fetch` baixa o histórico remoto sem alterar o trabalho local.
- `pull` busca e integra alterações remotas.
- `push` publica commits locais.
