# 2.1 Instalar o Git

Recomenda-se o Git 2.23 ou mais recente para os exemplos de `git switch` e `git restore` usados adiante. Versões mais antigas podem exigir comandos equivalentes, como `git checkout`.

Instale o Git usando o gerenciador de pacotes ou instalador recomendado para o seu sistema operacional. Confirme a instalação:

```bash
git --version
```

A versão exata pode variar. O comando deve mostrar uma versão, e não um erro.
