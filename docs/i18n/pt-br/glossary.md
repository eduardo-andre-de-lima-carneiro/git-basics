# Glossário

- **Commit:** Um instantâneo nomeado no histórico do repositório.
- **Árvore de trabalho:** Os arquivos atualmente disponíveis para edição.
- **Área de staging:** As alterações selecionadas para o próximo commit.
- **Branch:** Uma referência móvel para uma linha de commits.
- **Remoto:** Um local nomeado de repositório usado para compartilhar o histórico.
- **Clone:** Uma cópia local de um repositório existente.
- **Merge:** A integração dos históricos de duas linhas de desenvolvimento.
- **Integração com IDE:** Recursos do Git expostos dentro de um editor ou IDE, como preparação, diffs, histórico e resolução de conflitos.
- **Hunk:** Um bloco contíguo de linhas alteradas dentro de um arquivo que pode ser preparado isoladamente.
- **Ferramenta de merge:** Um programa externo definido em `merge.tool` e chamado por `git mergetool` para resolver conflitos.
- **Ferramenta de diff:** Um programa externo definido em `diff.tool` e chamado por `git difftool` para visualizar mudanças.
- **Credential helper:** Um componente que guarda e fornece as credenciais do Git para que não sejam redigitadas a cada push.
