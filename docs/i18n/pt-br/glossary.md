# Glossário

- **Commit:** Um instantâneo nomeado no histórico do repositório.
- **Árvore de trabalho:** Os arquivos atualmente disponíveis para edição.
- **Área de staging:** As alterações selecionadas para o próximo commit.
- **Branch:** Uma referência móvel para uma linha de commits.
- **Remoto:** Um local nomeado de repositório usado para compartilhar o histórico.
- **Clone:** Uma cópia local de um repositório existente.
- **Merge:** A integração dos históricos de duas linhas de desenvolvimento.
