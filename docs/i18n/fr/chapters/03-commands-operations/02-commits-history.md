# 3.2 Commits et historique

Voici quelques commandes utiles pour examiner l'historique :

```bash
git log --oneline --decorate --graph
git show <commit>
git diff <commit-a> <commit-b>
```

Privilégiez des commits ciblés représentant chacun un changement logique. L'historique est plus facile à relire lorsque les messages de commit utilisent une description précise, formulée à l'impératif.
