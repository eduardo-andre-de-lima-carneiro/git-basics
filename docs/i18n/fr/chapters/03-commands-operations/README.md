# Chapitre 3 : Commandes et opérations

Ces sections transforment les concepts en flux de travail quotidiens reproductibles et en techniques de récupération. Chaque leçon explique ce qu'une commande fait réellement en coulisses — pas seulement comment la taper — et renvoie vers la documentation officielle de Git pour que vous puissiez vérifier le comportement par vous-même.
