# 2.3 Dépôts locaux et distants

Commencez localement avec `git init`, ou copiez un projet existant avec `git clone <repository-url>`. Examinez le dépôt distant configuré avec :

```bash
git remote -v
```

Utilisez un dépôt d'exercice pendant votre apprentissage. N'expérimentez jamais avec des commandes destructrices dans une copie de travail de production.
