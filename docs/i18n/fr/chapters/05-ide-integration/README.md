# Chapitre 5 : Intégration aux IDE et aux éditeurs

L'essentiel du travail quotidien avec Git se fait à l'intérieur d'un éditeur de code ou d'un IDE. Les commandes des chapitres précédents continuent de s'exécuter en dessous ; l'éditeur ajoute une couche visuelle pour préparer les changements, comparer, consulter l'historique, changer de branche et résoudre les conflits. Ce chapitre explique d'abord les idées communes, puis montre comment elles apparaissent dans Visual Studio Code, Visual Studio et les IDE JetBrains, suivi d'un tour d'horizon des autres éditeurs et d'une note sur les flux assistés par IA.
