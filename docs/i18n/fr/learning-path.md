# Parcours d'apprentissage

Ce cours s'adresse aux personnes qui débutent avec Git ou qui passent de Subversion à Git.

1. Lisez le chapitre 1 pour construire le bon modèle mental.
2. Terminez le chapitre 2 et vérifiez Git localement avec `git --version`.
3. Parcourez le chapitre 3 dans un dépôt d'exercice que vous pouvez supprimer.
4. Recommencez les exercices jusqu'à ce que le flux de travail devienne prévisible.

Chaque section doit associer une brève explication, un exemple de commande, le résultat attendu et un petit exercice.
