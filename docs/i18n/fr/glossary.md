# Glossaire

- **Commit :** instantané nommé de l'historique d'un dépôt.
- **Arbre de travail :** fichiers actuellement extraits pour être modifiés.
- **Zone de staging :** changements sélectionnés pour le prochain commit.
- **Branche :** référence mobile vers une suite de commits.
- **Dépôt distant :** emplacement nommé d'un dépôt utilisé pour partager l'historique.
- **Clone :** copie locale d'un dépôt existant.
- **Fusion :** intégration des historiques de deux lignes de développement.
- **Intégration aux IDE :** fonctions Git exposées dans un éditeur ou un IDE, comme la préparation, les diffs, l'historique et la résolution de conflits.
- **Hunk :** bloc contigu de lignes modifiées dans un fichier, que l'on peut préparer séparément.
- **Outil de fusion :** programme externe défini par `merge.tool` et lancé par `git mergetool` pour résoudre les conflits.
- **Outil de diff :** programme externe défini par `diff.tool` et lancé par `git difftool` pour visualiser les changements.
- **Credential helper :** composant qui stocke et fournit les identifiants Git afin de ne pas les ressaisir à chaque push.
