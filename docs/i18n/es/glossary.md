# Glosario

- **Commit:** Una instantánea con nombre dentro del historial del repositorio.
- **Árbol de trabajo:** Los archivos actualmente preparados para editar.
- **Área de preparación:** Los cambios seleccionados para el próximo commit.
- **Rama:** Una referencia móvil a una línea de commits.
- **Remoto:** Una ubicación de repositorio con nombre que se usa para compartir el historial.
- **Clon:** Una copia local de un repositorio existente.
- **Merge:** La integración de historiales de dos líneas de desarrollo.
- **Integración con IDE:** Funciones de Git expuestas dentro de un editor o IDE, como la preparación, los diffs, el historial y la resolución de conflictos.
- **Hunk:** Un bloque contiguo de líneas modificadas dentro de un archivo que se puede preparar por separado.
- **Herramienta de fusión:** Un programa externo definido en `merge.tool` y ejecutado por `git mergetool` para resolver conflictos.
- **Herramienta de diff:** Un programa externo definido en `diff.tool` y ejecutado por `git difftool` para ver los cambios.
- **Credential helper:** Un componente que guarda y proporciona las credenciales de Git para no reescribirlas en cada push.
