# Ruta de aprendizaje

Este curso está diseñado para personas que están empezando con Git o que vienen de Subversion.

1. Lee el capítulo 1 para construir el modelo mental adecuado.
2. Completa el capítulo 2 y verifica Git localmente con `git --version`.
3. Trabaja el capítulo 3 en un repositorio de práctica desechable.
4. Repite los ejercicios hasta que el flujo de trabajo resulte predecible.
5. Usa el capítulo 4 para la plataforma de tu equipo y el capítulo 5 para tu editor o IDE.

Cada sección debe combinar una explicación breve, un ejemplo de comando, el resultado esperado y un ejercicio pequeño.
