# Capítulo 5: Integración con IDE y editores

La mayor parte del trabajo diario con Git ocurre dentro de un editor de código o un IDE. Los comandos de los capítulos anteriores siguen ejecutándose por debajo; el editor añade una capa visual para preparar cambios, ver diferencias, consultar el historial, cambiar de rama y resolver conflictos. Este capítulo explica primero las ideas compartidas y luego muestra cómo aparecen en Visual Studio Code, Visual Studio y los IDE de JetBrains, seguido de un recorrido por otros editores y una nota sobre los flujos asistidos por IA.
