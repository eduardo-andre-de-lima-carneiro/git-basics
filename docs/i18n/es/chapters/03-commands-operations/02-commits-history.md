# 3.2 Commits e historial

Entre los comandos útiles para inspeccionar se encuentran:

```bash
git log --oneline --decorate --graph
git show <commit>
git diff <commit-a> <commit-b>
```

Prefiere commits enfocados que representen un único cambio lógico. El historial es más fácil de revisar cuando los mensajes usan una descripción específica y en modo imperativo.
