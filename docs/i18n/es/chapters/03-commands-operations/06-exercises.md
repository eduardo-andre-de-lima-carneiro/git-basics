# 3.6 Ejercicios prácticos

Completa estos ejercicios en un directorio temporal:

1. Inicializa un repositorio, crea un archivo y haz dos commits enfocados.
2. Crea una rama, cambia la misma línea de forma diferente y resuelve el conflicto de merge.
3. Añade un remoto, descarga su historial y compara las ramas locales y remotas.
4. Practica cómo restaurar una edición sin preparar, quitar un archivo del área de preparación y revertir un commit.

En cada ejercicio, registra el comando utilizado, el estado anterior y el resultado que muestra `git status`.
