# 1.3 El modelo distribuido de Git

Un repositorio individual normalmente tiene un árbol de trabajo, un historial local y repositorios remotos opcionales. Un remoto es un punto de colaboración, no la definición de Git en sí.

Las operaciones habituales tienen propósitos distintos:

- `clone` copia un repositorio.
- `fetch` descarga el historial remoto sin cambiar el trabajo local.
- `pull` obtiene e integra los cambios remotos.
- `push` publica los commits locales.
