# 2.1 Instalar Git

Se recomienda Git 2.23 o posterior para los ejemplos de `git switch` y `git restore` usados más adelante. Las versiones anteriores pueden requerir comandos equivalentes como `git checkout`.

Instala Git con el gestor de paquetes o el instalador recomendado para tu sistema operativo. Confirma la instalación:

```bash
git --version
```

La versión exacta puede variar. El comando debería mostrar una versión en lugar de un error.
