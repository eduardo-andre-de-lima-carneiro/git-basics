# 2.3 Repositorios locales y remotos

Empieza localmente con `git init` o copia un proyecto existente con `git clone <repository-url>`. Inspecciona el remoto configurado con:

```bash
git remote -v
```

Usa un repositorio de práctica mientras aprendes. Nunca experimentes con comandos destructivos en una copia de trabajo de producción.
