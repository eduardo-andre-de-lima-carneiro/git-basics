# 3.6 Practical Exercises

Complete these in a temporary directory:

1. Initialize a repository, create a file, and make two focused commits.
2. Create a branch, change the same line differently, and resolve the merge conflict.
3. Add a remote, fetch its history, and compare local and remote branches.
4. Practice restoring an unstaged edit, unstaging a file, and reverting a commit.

For each exercise, record the command used, the state before it, and the result shown by `git status`.
