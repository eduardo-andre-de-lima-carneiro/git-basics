# Chapter 5: IDE and Editor Integration

Most day-to-day Git work happens inside a code editor or IDE. The commands from earlier chapters still run underneath; the editor adds a visual layer for staging, diffing, history, branching, and conflict resolution. This chapter explains the shared ideas first, then shows how they appear in Visual Studio Code, Visual Studio, and the JetBrains IDEs, followed by a short tour of other editors and a note on AI-assisted workflows.
